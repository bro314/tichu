## 1. Why & Goal

Active production tables are hitting BGA's hard 128 KB (`131,072` B) single-request notification ceiling inside `Table::sendNotificationPacket()` during zombie turn cascades (Sentry `#801556` at `134,580` B; `#801382` at `131,517` B). Alongside this crash, five silent defects undermine game integrity, privacy, SQL safety, and release safety:

1. **Real-time `capturedCards` leak**: `tichu.game.php::getAllDatas()` ships every captured card (with captor `card_location_arg`) to clients even when `isAllInfoExposed` is `0`.
2. **Production `devConsole` opponent-hand leak**: `stNextPlayer()` broadcasts `NotificationManager::devConsole()` containing `$beatingCombo->description` across all hidden hands in turn-based production tables.
3. **SQL interpolation, `shuffle()`, and session hazards**: raw interpolation in `LogManager`, `CardManager`, `PlayerManager`, and `upgradeTableDb()`; native `shuffle()` in `PlayerManager::setupPlayers()`; hidden `Tichu::getCurrentId()` fallback in `PlayerManager::getNextPlayers()`.
4. **Rollback-blind `checkVersion()`**: `global[300]` (`game_db_version`) only increments forward and notifications carry no version field, leaving `traceNotif()` disconnected from deploys and unable to detect rollbacks.

Goal: eliminate both Sentry 128 KB crashes and both info leaks, enforce DB/PRNG/session guardrails across all managers, and deliver rollback-aware client/server version parity with full 4-way live-game compatibility.

## 3. Architectural Decisions & Trade-offs

1. **128 KB Zombie & Bot Cascade Circuit Breaker — All-Zombie End + Periodic Flush (Recommended)**
   - _All-zombie table termination_: Inside `zombieTurn()`, query Tichu's own `player` table (`SELECT COUNT(*) FROM player WHERE player_zombie = 0 AND player_eliminated = 0`, matching [`bga-std-schema.sql#L14`](file:///Users/brohlfs/git/tichu/local/bga-std-schema.sql#L14) & [`Table.php#L1972-L2025`](file:///Users/brohlfs/git/tichu/local/Bga/GameFramework/Table.php#L1972-L2025) — **never** query `bga_*` tables). If `0` live players remain, emit `$this->logProdWarn("all_players_zombie_end", ...)` and end cleanly via `$this->gamestate->jumpToState(ST_GAME_END)` (`stGameEnd()`). Guard top of `zombieTurn()` against `ST_GAME_END` / `"gameEnd"` so subsequent iterations in `checkZombieTurn()`'s multiactive loop exit without throwing `VisibleSystemException`.
   - _1–3 zombie cascades_: Deduplicate `${player_name} makes a zombie turn` `NotificationManager::log()` to once per `player_id` per request via `$this->zombieLoggedInRequest` (since `playCombo`/`pass`/`grandTichuBet` already identify the acting player), and flush accumulated packets every `15` steps via `$this->sendNotifications()` ([`Table.php#L3445`](file:///Users/brohlfs/git/tichu/local/Bga/GameFramework/Table.php#L3445)). Clamp `TichuBot::actForOtherPlayers()` `$maxSteps` defensively to `[1, 40]` (`stepSingleBotTurn` already flushes per step via [`refreshLockStateAfterBotStep()`](file:///Users/brohlfs/git/tichu/tichu.game.php#L205-L214)).
   - _Rejected alternatives_: Early no-op `return` with an active zombie throws `ZombieStateException` in [`checkReturnState()`](file:///Users/brohlfs/git/tichu/local/Bga/GameFramework/Table.php#L3389-L3409); calling `forceAbandon()` cancels tables even when 1–3 players remain active; routing zombies through `TichuBot` breaks simple-zombie behavior tested in [`integration-tests.php#L2637-L2656`](file:///Users/brohlfs/git/tichu/local/integration-tests.php#L2637-L2656).

2. **Rollback-Aware `codeVersion` Constant & Centralized Notification Envelope (Recommended)**
   - Define `TICHU_CODE_VERSION` in [`modules/Constants.php`](file:///Users/brohlfs/git/tichu/modules/Constants.php) synced with `package.json` `"version"` on release builds (**never** edit `version.php`; never read files or call `exec()` at runtime due to Studio `workspace.blocked-files`).
   - Add `"codeVersion" => TICHU_CODE_VERSION` to `getAllDatas()` (keeping `gameVersion` intact) and route all notification emitters in `NotificationManager.php` through private `broadcast()` / `notifyPlayerWithVersion()` helpers merging `"codeVersion" => TICHU_CODE_VERSION`. Update [`local/check-contracts.php#L604-L695`](file:///Users/brohlfs/git/tichu/local/check-contracts.php#L604-L695) so static contract checking inspects those wrappers cleanly while preserving strict domain-key parity against `TichuNotificationMap`.
   - Inject `__TICHU_CODE_VERSION__` during `package.json` `esbuild` bundling (`typeof __TICHU_CODE_VERSION__ !== "undefined"`) so `setup()` catches CDN-cached stale JS on initial load, while `checkVersion()` skips when `this.isReadOnly()` and flags skew whenever `serverCodeVersion !== this.initialCodeVersion` (detecting both `V1 -> V2` upgrades and `V2 -> V1` rollbacks), falling back to `gameVersion` parity for pre-Plan-01 servers.
   - _Rejected alternative_: Mutating `global[300]` (`game_db_version`) downward — BGA executes no `downgradeTableDb()`, making `global[300]` strictly monotonic.

3. **`devConsole` Studio-Only Guard & Real-Time `capturedCards` Suppression (Recommended)**
   - Preserve `$impossibleToBeat = is_null($beatingCombo)` inside `stNextPlayer()` (`#L1455-L1468`) for turn-based auto-skipping, and wrap only `NotificationManager::devConsole(...)` with `if ($this->getBgaEnvironment() === "studio")`. Inside `NotificationManager::devConsole()`, route non-`"studio"` callers to `Tichu::$instance->trace((string) $msg)` (`Table::getBgaEnvironment()` at [`Table.php#L132-L155`](file:///Users/brohlfs/git/tichu/local/Bga/GameFramework/Table.php#L132-L155)).
   - Return `capturedCards: []` from `getAllDatas()` when `!$this->isAllInfoExposed()`, and apply the same guard in `src/tichu.ts` and `src/elements/game-model.ts` so neither network responses nor `window.tichuDebugSnapshot()` leak captured cards in real-time games.

4. **SQL Escaping, `bga_rand` Fisher-Yates & Mandatory `$pId` (Recommended)**
   - Replace raw SQL interpolation across `LogManager`, `CardManager`, `PlayerManager`, and `tichu.game.php` with `Table::escapeStringForDB()` and `(int)` casts; update `tests/stubs.php` so PHPUnit runs against non-null escaping; fix `PlayerManager::getSelectStmnt()` `player_*` bug; replace `shuffle()` with Fisher-Yates `Table::bga_rand(0, $i)`; require explicit `int $pId` in `PlayerManager::getNextPlayers()`.

private checkVersion(serverCodeVersion?: unknown, serverDbVersion?: unknown): boolean {
  if (this.isReadOnly()) return true;
  const srvCode = typeof serverCodeVersion === "string" ? serverCodeVersion : "";

      Number(this.gamedatas?.gameVersion ?? 0) === 0 ||

  return match;
