## 1. Why & Goal

BGA Translation HQ populates translation dictionaries exclusively via **static source scanning** of literal PHP `clienttranslate("...")` strings and literal bundled `tichu.js` `_("...")` calls. Tichu fails static extraction across both layers, leaving non-English players seeing English buttons, card tooltips, status labels, score headers, and trick logs ([#78193](https://boardgamearena.com/bug?id=78193), [#175241](https://boardgamearena.com/bug?id=175241)):

1. **`esbuild` mangled Lit translation helpers**: 10 Lit modules define local `const t = ...` or `function translate(...)`, which `esbuild` renames (`t4`..`t14`) or keeps (`translate`). Auditing bundled `tichu.js` (`660,955` bytes) confirms only **21** literal `_("...")` calls exist alongside **75** invisible calls (`t4`: 1, `t5`: 4, `t6`: 10, `t7`: 2, `t8`: 5, `t9`: 3, `t10`: 21, `t11`: 15, `t12`: 1, `t13`: 1, `t14`: 2, `translate`: 10) plus **13** dynamic/concatenated `_(` calls.
2. **Concatenated & bare PHP/TS strings**: `CardManager::cardToStr()` and `Combo.php` concatenate raw English phrases (`"Pair of Jacks"`, `"Run of 5 cards from 7 to Jack"`) without `clienttranslate()`, while `src/tichu.ts` concatenates `"Give cards to " + leftLabel` (#175241) and `"no " + s + "tichu"` inside `_()`.
3. **Why `&dummyTranslations` masked the failure**: Studio's `ly_studio.js:18046-18050` (and `ly_metasite.js:20261-20265`) overrides `globalThis._` at runtime (`«${t}»`), so `t5("Round:")` and `NotificationManager::playCombo` (`"i18n" => ["combo_name"]`) appeared bracketed in Studio even though Translation HQ extracted **0** dictionary keys from them.

**Goal**: Make every player-visible string statically extractable in PHP and `tichu.js`, localize dynamic logs and tooltips in live play and `gamereview`, and fail CI if bundled JS ever hides `_("...")` literals again.

## 3. Architectural Decisions & Trade-offs

1. **Global `_` + Localize-at-Origin + `substituteTemplate()` in TS (Eliminating `esbuild` Mangling)**:
   - **Option A (Recommended)**:
     - Keep `declare function _(str: string): string` global in [bga-framework.d.ts](file:///Users/brohlfs/git/tichu/src/types/bga-framework.d.ts#L66) and never declare local `const _` or `function _` in any TS file (preventing `esbuild` `_2`/`_3` renaming).
     - Initialize `if (typeof (globalThis as any)._ !== "function") (globalThis as any)._ = (s: string) => s;` once at module load in `src/elements/elements.ts` and `src/elements/combo-validator.ts`, preserving `&dummyTranslations` in BGA and enabling Node `test:validator`.
     - Replace all `t(...)` / `translate(...)` wrappers with direct literal `_("...")` calls. In `combo-validator.ts`, add `substituteTemplate(tpl, args)` (browser `globalThis.dojo?.string?.substitute`, Node `${key}` regex fallback) and `formatLocalizedComboDescription(combo)`, keeping canonical English `Combo.description` intact for parity and `resolveMissingPhoenixMetadata` (`combo-validator.ts:350,370,388`), plus `translateDynamic(s)` solely as legacy DB fallback in `tichu-last-played.ts:381`.
   - **Option B (Post-bundle `tichu.js` AST/regex rewrite)**: Rejected — brittle across two-stage `esbuild` bundling and fails dynamic templates.

2. **Recursive PHP `{ log, args }` `playCombo` Payload & 2-Release Rollout**:
   - Verified in BGA platform core (`ly_studio.js:26974-27020`, `ly_metasite.js:19315-19323`): `{ "log" => clienttranslate(...), "args" => [...] }` translates natively in live games **and** `gamereview` archives **only** if outer `"i18n"` omits the sub-log key (`format_string_recursive` invokes `clienttranslate_string()` on `i18n` entries before recursing sub-logs), inner `args` is a non-null array, and nested `i18n` lists scalar string keys only.
   - **Option A (Recommended — 2-Release Expand-Then-Contract)**:
     - _Release 1_: Harden `src/tichu.ts` (`notif_playCombo`), `game-model.ts` (`1068`), `decodeHtmlEntities` (`typeof text === "string"`), and `tichu-last-played.ts` to accept `combo_name: string | I18nLogPayload`; ship all JS extraction, Mahjong `UserException`, `CardManager`, `tableWindow`, `acceptCards`/`passCards`, and `Combo::toLogSpec()` changes while keeping `NotificationManager::playCombo` `"combo_name" => $combo->description` as `string`.
     - _Release 2 (after ~24–48h live tab rotation)_: Switch `NotificationManager::playCombo` `"combo_name"` to `$combo->toLogSpec()` and omit `"combo_name"` from outer `"i18n"`.
     - **Rationale**: Prevents crashing unrefreshed `OLD open JS` tabs (`decodeHtmlEntities(lastCombo.description)` `TypeError: text.replace is not a function` at `combo-validator.ts:113,1668`) while **preserving existing Translation HQ translations** for `'${player_name} plays ${combo_name}'` (proven live by `[spielt]` in `#78193`).
   - **Option B (Single-deploy dual key `${combo_label}`)**: Emit both legacy `"combo_name"` string and `"combo_label" => $combo->toLogSpec()`, switching `tichu.game.php:504,508` to `${combo_label}`. Safe in 1 deploy, but orphans existing `'${player_name} plays ${combo_name}'` translations.
   - **Option C (Single-deploy direct switch of `combo_name`)**: Rejected — crashes unrefreshed live tabs until F5 reload.

3. **`CardManager::cardToStr()` Plurals, Terminology & `UserException(NotificationMessage)`**:
   - **Card Terminology**: Keep `"Dog"` / `"Mahjong"` in `CardManager::cardToStr()` (matching `Combo.php`, `combo-validator.ts`, and #78193) and remove deprecated `self::_()` in `material.inc.php:34-37`.
   - **Plurals & `i18n` Filtering**: Wrap faces, specials, and explicit plurals (`"2s".."10s"`, `"Jacks".."Aces"`) in `clienttranslate()` inside `CardManager::cardToStr()`; add `CardManager::isTranslatableCardStr($card, $plural)` so `"i18n"` arrays in `wishMade`, `acceptCards`, `passCards`, and `Combo::toLogSpec()` never pass bare numeric `"0"` / `"2".."10"` (always passing `'i18n' => $filteredArray` inside the literal payload array so `check-contracts.php:631` parses cleanly).
   - **Mahjong Exception Localization**: Replace `sprintf($this->_("You must grant..."), ...)` (`tichu.game.php:477,804`) with `new UserException(new \Bga\GameFramework\NotificationMessage(clienttranslate('You must grant the Mahjong Wish and play a ${rank}'), $args))` (`ly_studio.js:28875`, `_ide_helper.php:1245-1248,2390`). Preserve existing already-extracted phrasing unless broken typos (`"tha"` -> `"that"`).
