## 1. Why & Goal

Four structural layout and UI-chrome flaws block mobile/tablet playability and prompt complaints like [#257135](https://boardgamearena.com/bug?id=257135):

1. **BGA Viewport Spec Violation & `0.4x` Micro-Shrinking**: [`gameinfos.inc.php`](file:///Users/brohlfs/git/tichu/gameinfos.inc.php#L79) sets `"min" => 920` outside BGA's `[320, 740]` bounds, forcing `920px` virtual mobile viewports and triggering `mobile_version` below `1160px` (`interfaceMinWidth + 240`), while [`Tichu::rescale()`](file:///Users/brohlfs/git/tichu/src/tichu.ts#L1246-L1275) scales the board down to `0.4x` (`40x60px` cards).
2. **Dated Text Wall & Stray Spectator/`gameEnd` Chrome ([#257135](https://boardgamearena.com/bug?id=257135))**: [`TichuActionBar::renderPlayButtonContent()`](file:///Users/brohlfs/git/tichu/src/elements/tichu-action-bar.ts#L292-L337) renders a beige bar containing `<h3>My hand</h3>` even for spectators (`isReadOnly()`) and at `gameEnd`, while [`TichuHand`](file:///Users/brohlfs/git/tichu/src/elements/tichu-hand.ts#L46-L91) wastes `250px` right margin on `#myhand` and displays 6 bracketed `[text links]` plus 11 tiny `14px` swatches unconditionally.
3. **Cramped Single-Row 14-Card Hand ([#164400](https://boardgamearena.com/bug?id=164400))**: [`TichuStock`](file:///Users/brohlfs/git/tichu/src/elements/tichu-stock.ts#L63-L75) locks `#stock` to a single `150px`-tall flex line (`17px` slices on phones).
4. **Hardcoded Desktop Widths**: Fixed pixel widths in `<tichu-last-played>`, `<tichu-pass-area>`, `<tichu-action-bar>`, `<tichu-value-choice>`, `<tichu-trick-modal>`, and `<tichu-played-cards>` overflow `375px`, `500px`, and `740px` screens.

**Goal**: Make Tichu BGA-compliant (`min => 500`), clutter-free (compact pill bar + collapsible `⚙️ Settings` drawer, zero empty spectator/`gameEnd` chrome), and responsive with zero horizontal overflow (`375px`–`1440px`), including automatic 2-row 14-card hands that preserve FLIP/WAAPI animations.

## 3. Architectural Decisions & Trade-offs

1. **BGA `game_interface_width.min` & `rescale()` Breakpoint (`500` + CSS `< 760px` vs `740` Transform Everywhere)**
   - **Recommended**: Set `'min' => 500` in [`gameinfos.inc.php`](file:///Users/brohlfs/git/tichu/gameinfos.inc.php#L79). In [`Tichu::rescale()`](file:///Users/brohlfs/git/tichu/src/tichu.ts#L1246-L1275), keep `widthMin = 900` (`factor >= 1.0` clears `transform` at `>= 900px`, gentle `0.84..1.0` at `760..899px`), and **disable `transform: scale`** below `760px` (`transform = ""`, `gameElement.style.width = "100%"`, toggle `.responsive-compact` on `#game_play_area`) so `375px–759px` uses true `1x` CSS responsive layout with `>= 44px` tap targets (matching BGA guidelines & `Odin` in [`docs/BGA_OPEN_SOURCE_ECOSYSTEM.md`](file:///Users/brohlfs/git/tichu/docs/BGA_OPEN_SOURCE_ECOSYSTEM.md#L23-L74)). Preserve `widthMin = 1000` transform scaling when `experimentalArchiveModeEnabled` is true.
   - _Rejected_: Setting `740` with unconditional transform scale (`0.5x` on `375px` phones remains illegible).

2. **Responsive 14-Card Hand Wrapping (`<tichu-stock>` Auto 2-Row Split vs Single-Row Squeeze vs Manual Row Buttons)**
   - **Recommended**: Add `@property({ type: Boolean }) wrapRows = false` on `<tichu-stock>` (enabled on `#myhand` and `<tichu-trick-modal>`). Whenever `cards.length >= 8` and single-row visible slice `< 42px` (`< ~640px`), automatically split into **2 centered `.stock-row` flex rows** (`Math.ceil(N / 2)` + `Math.floor(N / 2)`, e.g. `7 + 7`) with `effectiveScale = width < 420 ? 0.85 : this.scale`, `padding-top: 22px`, and `row-gap: 24px` so Row 2's `-20px` selection lift never overlaps Row 1's rank corners.
   - _Rejected_: Ultra-tight single row (`17px` slices mis-tap) and manual row-move buttons (superseded by Plan 05 `#22264` drag-reorder).

3. **Modern Compact Controls & Spectator/`gameEnd` Chrome ([#257135](https://boardgamearena.com/bug?id=257135))**
   - **Recommended**: Return empty template in `<tichu-action-bar>` when `isReadOnly()` or `stateName === "gameEnd"`, drop the `<h3>My hand</h3>` fallback on inactive/waiting turns, reclaim `#myhand`'s `250px` right margin, and replace `#prefs`/`#themes` text links with a compact pill utility bar (`Rank`/`Suit` segmented toggle, `List`/`Square` pill, optional `Experimental Replay` pill, and `⚙️ Settings` button toggling a responsive `#tichu_settings_drawer` for layout, clockwise, Tiki art, animations, and 11 theme swatches). Preserve legacy DOM IDs (`#order_by_rank`, `#square_table`, `#theme0..10`, etc.) so existing contracts stay intact.

4. **Square vs List Table & Pass Area below `760px`**
   - **Recommended**: In `<tichu-last-played>`, change `.squareTable` column minimums to `minmax(0, ...)` at `640px–899px` (so `740px` keeps the 5-col cross cleanly), use a 2-col spatial diamond (`top` full row, `left`/`right` stacked seat boxes side-by-side respecting `.clockwise`, `bottom` full row) at `440px–639px`, and 1-col stack `< 440px`. In `<tichu-pass-area>`, replace `width: 560px` with fluid `max-width: 560px` and responsive card scale.

## 4. 4-Way Live-Game Compatibility & Concurrency Audit

- **1. `OLD DB -> NEW PHP + NEW JS`**: Pure metadata (`gameinfos.inc.php`) + frontend bundle/CSS release. No `dbmodel.sql`, `states.inc.php`, `global_id`, `actionlog`, `gameoptions`, or `stats` changes; open tables rehydrate identically from `getAllDatas()`.
- **2. `OLD open JS tab <-> NEW PHP`**: Backend PHP (`tichu.game.php`, `tichu.action.php`, `NotificationManager.php`) is untouched, so already-open tabs continue calling the exact same endpoints and receiving identical notification payloads.
- **3. `NEW open JS tab <-> OLD PHP` (Rollback)**: `NEW` JS calls only existing `tichu.action.php` endpoints, existing `GameModel` subjects, and existing preferences `100`–`105`; works seamlessly against `OLD` PHP.
- **4. `NEW DB / actionlog -> OLD PHP + OLD JS` (Rollback)**: Writes zero new DB columns, `global` rows, or `actionlog` events; rolling back `gameinfos.inc.php` (`Reload game informations`), `tichu.js`, and `tichu.css` leaves zero residue.
- **Concurrency, Autopass, Replay & Platform Guardrails**:
  - **Locks & `@thoun` Autopass**: Zero server action or `player_pass` changes (`acquireGameLock()`, `acquireGameLockOrFail()`, `syncStaleReturnState()`, and `AUTOPASS_NONE/ONCE/TRICK` resets remain untouched).
  - **`<tichu-replay>`**: `experimentalArchiveModeEnabled` keeps `widthMin = 1000` transform scaling in `rescale()` so replay grid layout is unaffected; no notification parsing changes.
  - **`local/import-bug-sql.php`**: Zero impact on the 7 `player_id` remap surfaces.
  - **Studio Safety, Dark Mode & Safari**: Zero forbidden platform APIs (`workspace.blocked-files` clean via `npm run test:contracts`); no `filter: drop-shadow(...)` on cards (`.dj_safari` GPU lag rule); define `--tichu-ctrl-*` dark-mode variables on `html` & `html[data-theme="dark"]` in `tichu.css` (do **not** use `:host-context()`, which fails in Firefox/Safari Shadow DOM); wrap all new labels (`Settings`, `Rank`, `Suit`, `Table`, `Theme`, etc.) in `t()` with literal strings.
